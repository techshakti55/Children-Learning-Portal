## Content target

Four lessons; two worked examples per lesson; five practice questions per lesson; ten mixed revision questions. Include hint, explanation, learning objective and prerequisite labels. Lesson 4 is optional enrichment.

## Accuracy and prerequisites

Natural numbers start at 1. Zero is even. Both 0 and 1 are neither prime nor composite. The only even prime is 2. Number-family membership overlaps. Co-prime pairs need not contain prime numbers. Teach common factors before co-prime pairs; avoid untaught HCF calculations in basic Number Types practice.
